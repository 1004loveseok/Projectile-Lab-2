# Projectile Lab — Motion Studio v3

한 웹사이트에서 두 가지 방식으로 포물선 운동을 경험하는 교육용 프로젝트입니다.

## 모드 1: 물리학 실험실
- 초기 속력, 발사 각도, 질량, 중력가속도 숫자 입력
- 포물선 궤적 애니메이션 및 시간 스크럽
- 최고 높이, 비행 시간, 수평 도달 거리, 최고점 도달 시간 계산
- 순간 속도 벡터와 가속도 벡터 표시
- 수평 속도, 수직 속도, 속력의 시간 그래프
- 실험 기록 저장 및 비교

## 모드 2: 포물선 챌린지
- 별도 모드 선택 화면에서 진입하는 아케이드형 퍼즐
- 드래그로 새총을 당겨 발사 방향과 세기 조절
- 구조물과 목표물, 제한된 발사 횟수
- 10개 스테이지와 순차 해금
- 재시작 및 스테이지 선택

게임은 만화풍의 완전한 디지털 퍼즐이며 실제 장치 제작이나 사용법을 안내하지 않습니다.

## 실행
`index.html`을 브라우저에서 열면 실행됩니다. 설치나 빌드 과정은 필요하지 않습니다.

## GitHub Pages
저장소 최상위에 `index.html`, `styles.css`, `app.js`, `README.md`를 업로드하고 Settings → Pages → Deploy from a branch → `main` → `/ (root)`를 선택하세요.

## 물리 모델
공기 저항을 무시하고 발사 높이와 착지 높이가 같다고 가정합니다.
- x(t) = v₀ cosθ · t
- y(t) = v₀ sinθ · t − ½gt²
- vₓ(t) = v₀ cosθ
- vᵧ(t) = v₀ sinθ − gt
- aₓ = 0, aᵧ = −g

속도 벡터는 매 순간의 수평·수직 속도 성분으로 다시 계산됩니다. 따라서 최고점에서는 수평 방향, 하강 중에는 오른쪽 아래 방향을 가리킵니다. 질량은 이상적 모델의 궤적에 영향을 주지 않습니다.
